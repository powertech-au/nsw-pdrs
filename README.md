# NSW Peak Demand Reduction Scheme (PDRS)

Powertech's plain-English guide to the NSW Peak Demand Reduction Scheme as amended by the
Peak Demand Reduction Scheme (Amendment No. 2) Rule 2026, plus a certificate calculator.

Live site: https://powertech-au.github.io/nsw-pdrs/

| Page | Purpose |
| --- | --- |
| `index.html` | Scheme explainer: BESS1-BESS5 and V2G1 activity definitions, the certificate equations, worked examples and the 2026 rule changes. |
| `calculator.html` | Estimates Peak Reduction Certificates and federal Cheaper Home Batteries STCs, with eligibility and minimum-payment checks. |
| `assets/` | Powertech logos and the self-hosted Fuglesans display face. |

Static HTML with no build step. Edit the files and push; GitHub Pages serves `main` from the
repository root.

Source of truth for edits is the OneDrive copy under
`Edapta - Documents\PDRS\PDRS website`.

Content is current as at 22 August 2026 and is general information, not legal or financial
advice. Where anything differs from the PDRS Rule, the Rule prevails.
